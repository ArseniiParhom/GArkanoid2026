# GArkanoid2026

Arkanoid clone created for the Introduction to Game Programming course.

## Tools

- Godot 4.7.2 .NET
- C#
- Visual Studio Code
- Git

## How to run

1. Open the project in Godot 4.7.2 .NET.
2. Open `Scenes/Levels/Level.tscn`.
3. Run the project.

## Input

### Move Left
- A
- Left Arrow
- Gamepad D-pad Left
- Gamepad Left Stick Left

### Move Right
- D
- Right Arrow
- Gamepad D-pad Right
- Gamepad Left Stick Right

### Launch Ball
- Space
- Gamepad South Button
